# 🏢 Toolify Enterprise ERP & Utility Suite

**Toolify Enterprise ERP** is a lightweight, multi-company workforce, officer, and task-tracking system designed for small businesses, retail stores, and growing teams. Built with pure HTML5, CSS3, and JavaScript, it requires zero backend configuration and runs seamlessly right inside the browser using secure local storage.

![Toolify Banner](https://images.unsplash.com/photo-1551288049-bebda4e38f71?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Key Features

* **Multi-Company Isolated Storage:** Each company can load its own name and manage its own separate workforce data without any data overlapping (powered by `localStorage`).
* **Role-Based Views & Filtering:** Instant switcher for CEO Master View, Plant Manager, Accountant, and HR Officer views.
* **Workforce & Task Assignment:** Easily assign tasks, departments, and check-in times to staff members.
* **Zero Backend Costs:** Client-side architecture means no database hosting or server maintenance fees.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
